# ATRI -My Dear Moments- · GBA 中文移植版

在 GBA 的小小屏幕上，重温那个逐渐沉入海中的夏天。

本项目将《ATRI -My Dear Moments-》适配为 GBA 视觉小说，**基于 [小鳥遊暁](https://t-satoru.top/) 汉化的版本移植**。感谢原作创作者与汉化者带来的故事与中文阅读体验。

> **本仓库不含图片、音频等素材文件，也不附带游戏 ROM。**
> 仓库保留游戏代码和完整中文剧情配置；素材与工程分开管理。仅下载本仓库无法直接游玩。

## 故事介绍

在海平面不断上升、许多城镇已被淹没的近未来，失去一条腿的少年斑鸠夏生回到了海边的小镇。

为了寻找沉在海底的遗物，他潜入水中，却意外唤醒了沉睡在舱中的机器人少女——亚托莉。她有着与人类相似的外表、丰富的表情，也总把“高性能”挂在嘴边。

一场从海底开始的相遇，将夏生与小镇上人们的生活重新连接。在残存的日常与逐渐变化的世界里，他们一起寻找值得守护的东西。

这是一段关于相遇、记忆、心与未来的夏日故事。

## GBA 版内容

- **完整中文剧情**：保留原有对白、旁白、选项和路线，不对剧情作删节或概括；较长对白仅作分页。
- **多结局体验**：保留两条普通结局及真结局，并保留对应的分支与解锁规则。
- **掌机阅读功能**：逐字显示、快进、自动播放、历史记录和设置。
- **存读档**：支持继续游戏与三个手动存档槽，记录已读状态。
- **画面适配**：背景、CG与角色表情适配240×160分辨率；已修复身体与表情混用尺寸导致的立绘错位。

当前移植覆盖34个故事脚本、12,172段原始对白，经过分页与控制节点转换后共12,280节点。

## 与原版的区别

本版以在 GBA 上阅读完整故事为目标，视听演出有相应简化：

- 背景保持比例并留边，人物和表情缩放后显示，同屏显示一名角色立绘。
- 原版复杂镜头、帧动画、叠加特效及OP/ED视频未复刻。
- 未收录完整语音；音乐使用35首曲目各7秒的循环节选。

“完整剧情”指文字、选项与路线完整保留，不代表原版全部视听演出的完整还原。

## 游戏操作

| GBA 按键 | 功能 |
| --- | --- |
| A | 显示整句、推进对白、确认选择 |
| B | 快进；部分菜单中返回 |
| 方向键 | 选择选项、菜单或存档槽 |
| Start | 打开游戏菜单 |
| Select | 切换自动播放 |

使用模拟器时，键盘映射以模拟器输入设置为准。已生成的游戏ROM可使用 [mGBA](https://mgba.io/) 打开。当前已进行mGBA运行验证，尚未完成实体GBA测试。

真结局需满足对应的普通结局通关条件后解锁，建议按自己的选择先体验故事。

## 关于存档

请保留游戏ROM对应的 .sav 文件，它保存你的游戏进度。更新版本前建议先备份；更改ROM文件名或目录后，模拟器可能改用另一份存档。

游戏内存档与模拟器即时存档是两套功能。跨版本更新建议优先保留并使用游戏内存档；如剧情结构发生变化，旧位置和已读记录可能重置。

本说明面向玩家介绍游戏。用于AI协助移植其他作品的通用模板另行提供。

## 问题反馈

如果遇到乱码、剧情跳转异常、存档问题或立绘表情错位，请记录：

- 章节、说话人及出现问题的对白原句。
- 使用的游戏版本、模拟器名称与版本。
- 触发步骤，例如读取存档后出现，或选择某个选项后出现。

请尽量避免在公开反馈中附带个人存档或完整素材包。
